# Price Comparison and Analytics System

## Overview

This project collects product information from multiple e-commerce platforms and compares prices, reviews, and trends.

## Objectives

- Build ETL pipelines
- Match identical products across platforms
- Track price history
- Analyze reviews and ratings
- Create analytics dashboard

## Technologies

- Python
- SQLite
- Pandas
- Streamlit
- Scikit-learn
